# divaar

بازارچهٔ آنلاین آگهی — یک اپلیکیشن سبک و بدون وابستگی (HTML + CSS + ES Modules) برای خرید و فروش کالا و خدمات.

## اجرا

```bash
npm test          # اجرای تست‌ها (Node 20+)
npm run serve     # سرو کردن اپ روی http://localhost:8080
```

## ساختار

```
divaar/
├── index.html          # پوستهٔ اپ
├── assets/styles.css   # توکن‌های طراحی و استایل پوسته
├── src/
│   ├── app.js          # bootstrap و حلقهٔ رندر
│   ├── state.js        # استور قابل‌مشاهده (observable store)
│   ├── ui.js           # هدر، empty state و اجزای مشترک
│   └── utils.js        # ارقام فارسی، فرمت قیمت/تاریخ، debounce
└── tests/              # هارنس تست بدون وابستگی
```

## جریان کار

- `main` همیشه قابل‌اجراست و فقط پوسته را دارد.
- هر قابلیت روی برنچ `feature/<name>` با حداقل سه کامیت معنادار توسعه می‌یابد.
- ادغام از طریق پول‌ریکوئست و پس از سبز شدن تست‌ها انجام می‌شود.
