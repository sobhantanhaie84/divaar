# راهنمای مشارکت

## نام‌گذاری برنچ‌ها

| نوع       | الگو                | مثال                    |
| --------- | ------------------- | ----------------------- |
| قابلیت    | `feature/<slug>`    | `feature/search-bar`    |
| رفع باگ   | `fix/<slug>`        | `fix/price-formatting`  |
| زیرساخت   | `chore/<slug>`      | `chore/test-harness`    |

## قرارداد کامیت‌ها

از [Conventional Commits](https://www.conventionalcommits.org/) استفاده می‌کنیم
